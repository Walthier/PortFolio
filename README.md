# Portfolio - Kevin Tobias Martinez 🚀

Portfolio profesional construido con **Vite**, **HTML5**, **CSS3** (Neo-Brutalismo Oscuro + Retro Y2K) y **JavaScript**.

---

## 🎨 Especificaciones del Diseño
- **Paleta de Colores**: 
  - Naranja: `#FFA500`
  - Rojo Intenso / Granate: `#780606`
  - Negro: `#000000`
- **Estética**: Neo-brutalismo oscuro con sombras sólidas (`4px 4px`), detalles retro terminal y toques de glassmorphism.
- **Tipografías**: Inspiradas en [Tamal Sen](https://tamalsen.dev/):
  - `Poppins` para títulos, encabezados y textos principales.
  - `Roboto Mono` para etiquetas técnicas, badges y nombres de archivo.

---

## 🛠️ Comandos de Desarrollo (Vite)

### 1. Iniciar el servidor de desarrollo local
```bash
npm run dev
```
> Abrirá el servidor local rápidamente en `http://localhost:5173`. Disfrutarás de recarga instantánea en caliente (Hot Module Replacement / HMR).

### 2. Generar el compilado para producción
```bash
npm run build
```
> Empaqueta y optimiza los archivos en la carpeta `dist/` listos para subir a producción o GitHub Pages.

### 3. Previsualizar la versión de producción
```bash
npm run preview
```
